# PrintSphere v1.7.7 (Knomi v2)

Adds GitHub reinstall on the Web Config, matching the StatusBar
Neuinstallation button.

## Changes

- **Reinstall** flashes the current GitHub Knomi OTA asset even when the
  device is already on that version.
- Install update stays reserved for a newer release.

## Assets

- `printsphere_full-v1.7.7-knomi_v2.bin` — USB factory flash
- `printsphere_ota-v1.7.7-knomi_v2.bin` — OTA for devices already on the Knomi identity
